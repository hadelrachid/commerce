# DomainCommerce

> Official plugin extension for the **[Domain-System OS](https://github.com/hadelrachid/domain-system)** ecosystem.

E-commerce engine, decoupled checkout, and multi-gateway financial settlement for Domain-System.

---

## 📌 Requirements

- **Domain-System OS (CockPit)** version 2.8 or higher.
- PHP 8.2+ with PDO, JSON, and ZIP extensions enabled.

---

## 🚀 Installation Guide for Domain-System (CockPit)

1. Download the `commerce.zip` distribution bundle from the [Releases](https://github.com/hadelrachid/commerce/releases/latest) page of this repository.
2. Log in to your Domain-System administration dashboard (`/admin`).
3. From the main sidebar menu, select **Modules (Plugins)**.
4. Click the **Add New** button situated at the top of the screen.
5. Choose the downloaded `commerce.zip` file and click **Install Now**.
6. The Domain-System OS will securely unpack the package into `src/Plugins/commerce` and register the plugin hooks immediately.

---

## ⚙️ Upgrades

When a new version is released, your Domain-System CockPit admin board will highlight the available upgrade and allow an instant one-click installation directly from this official repository.
